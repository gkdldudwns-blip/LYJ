# Jooniverstudio

내 캐릭터 그림 한 장을 올리고 포즈를 고르면, **같은 캐릭터·같은 그림체**로 그 포즈를 그려 주는 개인용 웹앱입니다.
이모티콘 제작과 인스타툰 작업에 쓰려고 만들었고, 그림은 Google Gemini 이미지 모델(Nano Banana)로 만듭니다.

## 할 수 있는 것

- **사람이 아니어도 돼요**: 캐릭터를 올리면 AI가 사람형 / 동물·생물 / 사물·기타인지와 몸 구조를 먼저 파악해요.
  병아리라면 "팔 대신 날개, 손동작은 날개로"처럼 정리하고, 포즈를 그 몸에 맞게 바꿔 그려요(사람 팔다리를 새로 붙이지 않아요).
- **캐릭터 관리**: 캐릭터를 여러 개 저장하고, 캐릭터마다 참고 그림을 최대 8장과 설명을 둘 수 있어요.
  정면이 아니어도 괜찮고, ★ 대표 그림을 바꿀 수 있어요.
- **결과를 참고 그림으로**: 마음에 든 결과를 "＋참고"로 캐릭터 참고 그림에 넣으면 다음 그림부터 더 일관되게 나와요.
  갤러리에서 여러 장을 골라 한꺼번에 넣을 수도 있어요(같은 그림은 한 번만 들어가요).
- **포즈 79종**: 기본 4 · 긍정 12 · 부정 17 · 정보성 9 · 일상 19 · 이모티콘 18. 손그림 마네킹 썸네일로 골라요.
  즐겨찾기(☆)로 자주 쓰는 포즈를 모아 둘 수 있어요.
- **내 포즈 추가**: 설명(한국어 가능)이나 참고 사진·스케치로 나만의 포즈를 만들어요.
- **한 번에 여러 장**: 포즈를 여러 개 고르고, 포즈마다 1~4장씩 만들어요. 실패한 그림은 다시 시도할 수 있어요.
- **이모티콘 옵션**: 그림 안에 문구 넣기(안녕!, 감사합니다 등), 흰 배경 투명하게, 360×360 / 540×540 / 1080×1080 크기 맞춤 저장.
- **내 갤러리**: 만든 그림은 브라우저에 기한 없이 저장되고, 여러 장을 골라 ZIP으로 받을 수 있어요.

결제·회원가입은 아직 없습니다. 나중에 붙일 수 있도록 기능을 나눠 두었어요.

## 실행하기 (내 컴퓨터)

준비물: [Node.js](https://nodejs.org) 20 이상

```bash
cd pose-studio
npm install
npm run dev
```

브라우저에서 http://localhost:3000 을 열고, 오른쪽 위 **설정**에서 Gemini API 키를 넣으면 바로 쓸 수 있어요.
API 키는 [Google AI Studio](https://aistudio.google.com/apikey)에서 만들 수 있어요.
**이미지 모델(Nano Banana 계열)은 Gemini 무료 등급에서 쓸 수 없어요.** 무료 키로 만들면 "무료 API 키로는 이미지 모델을 쓸 수 없어요"가 떠요.
Google AI Studio의 API 키 화면에서 결제 설정(Set up billing)으로 카드를 연결해 유료 등급을 켜 주세요.
Nano Banana 2.1 기준 1K 그림 1장에 약 $0.034(약 50원), 2K는 약 $0.05예요(2026년 10월 Google 요금표 기준).
캐릭터 분석에 쓰는 Flash 텍스트 모델은 비용이 아주 적어요.

> 내 컴퓨터에서만 쓸 때는 `pose-studio/.env.local` 파일에 `GEMINI_API_KEY=키` 를 적어 두어도 돼요.
> 이 방법은 키가 빌드 결과에 그대로 들어가므로, **인터넷에 올리는 배포에는 절대 쓰지 마세요.**

## 휴대폰에서도 쓰기 (배포)

`main` 브랜치에 `pose-studio/`가 바뀌면 GitHub Actions(`.github/workflows/deploy-pose-studio.yml`)가
자동으로 빌드해서 **GitHub Pages**에 올려요. 처음 한 번만 설정하면 돼요.

1. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꾸기
2. 이 코드를 `main`에 합치기 (또는 **Actions → Deploy Jooniverstudio → Run workflow**)
3. 몇 분 뒤 `https://<GitHub 아이디>.github.io/<저장소 이름>/` 주소로 열기
   (이 저장소는 https://gkdldudwns-blip.github.io/LYJ/)
4. 휴대폰에서 열고 설정에서 API 키 입력. 홈 화면에 추가해 두면 앱처럼 쓸 수 있어요.

Vercel·Netlify·Cloudflare Pages에 올려도 돼요. 이때는 Root Directory를 `pose-studio`로 지정하고 환경 변수는 넣지 마세요.

API 키는 각 브라우저에만 저장되므로, 다른 사람이 주소를 알아도 자기 키 없이는 그림을 만들 수 없어요.
그래서 별도 로그인 없이도 사실상 **나만 쓰는 앱**이 됩니다.

## 알아 두면 좋은 점

- **저장 위치**: 캐릭터·갤러리·내 포즈는 그 브라우저의 IndexedDB에 저장돼요. PC와 휴대폰은 자동으로 공유되지 않고,
  브라우저 데이터를 지우면 함께 지워져요.
- **다른 기기로 옮기기**: 설정(또는 내 갤러리) → **다른 기기로 옮기기**에서 백업 파일(.zip)을 만들어 다른 기기로 보내고,
  그 기기에서 불러오면 이어서 쓸 수 있어요. 같은 파일을 여러 번 불러와도 중복되지 않아요. API 키는 백업에 들어가지 않아요.
- **투명 배경**: 테두리와 이어진 흰 배경만 지워요. 선으로 둘러싸인 안쪽 흰색(얼굴 등)은 남아요.
- **한글 문구**: 모델이 가끔 글자를 틀리게 그려요. 그럴 땐 문구 없이 만든 뒤 직접 얹거나, 설정에서 Nano Banana Pro로 바꿔 보세요.
- **포즈 가이드**: 사람형 캐릭터에는 썸네일 그림을 함께 보내 포즈를 정확히 따라 하게 해요. 동물·사물 캐릭터에는 보내지 않아요.
  마네킹 모양(십자 얼굴선 등)이 결과에 섞이면 설정에서 꺼 보세요.
- **캐릭터 분석**: 몸 구조 분석은 캐릭터를 처음 올릴 때 Gemini Flash 모델로 한 번 해요. 결과가 틀리면 몸 구조와 설명을 직접 고치면 돼요.
- **개인정보**: 그림 요청은 `store: false`로 보내서 Google 쪽 대화 기록(Interactions)에 남기지 않아요.

## 코드 구조

| 파일 | 역할 |
|---|---|
| `constants.tsx` | 포즈 목록(이름·분류·프롬프트), 몸 구조 종류, 모델 목록, 기본값 |
| `public/poses/*.webp` | 포즈 썸네일(손그림 마네킹). 사람형 캐릭터에는 포즈 가이드로도 보내요 |
| `services/geminiService.ts` | Gemini Interactions API 호출, 캐릭터 분석, 프롬프트 |
| `services/imageUtils.ts` | 업로드 정리, 흰 배경 제거, 크기 맞춤, PNG/ZIP 저장 |
| `services/storage.ts` | IndexedDB(캐릭터·결과·내 포즈)와 설정 저장 |
| `App.tsx`, `components/` | 화면과 생성 대기열 |

포즈를 더 넣고 싶으면 `constants.tsx`의 `POSES` 배열에 한 줄 추가하고, 같은 이름의 썸네일을 `public/poses/<id>.webp`에 넣으면 돼요.
썸네일은 Higgsfield의 Nano Banana 2.1로 `front.webp`를 그림체 기준으로 삼아 그렸어요
(둥근 머리에 회색 십자 가이드선, 얼굴 없음, 짧은 팔다리, 검은 손그림 선, 흰 배경).

## 나중에 공개 서비스로 바꿀 때

- API 키를 사용자 브라우저가 아닌 **서버(백엔드)**에서 쓰도록 옮기기
- 회원가입·로그인, 사용자별 갤러리를 서버에 저장
- 크레딧 충전과 결제, 무료 체험 횟수, 워터마크 미리보기
